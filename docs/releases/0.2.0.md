# DecrampEQ 0.2.0

Initial public release of the MIT-licensed C++17 single-header IIR EQ library.

- Bell, shelves, low/high pass, notch, tilt, and band-pass responses fitted to
  analog magnitude prototypes over a finite band.
- Continuous 12–96 dB/oct cut slopes, with up to 16 biquads per band.
- Fixed-size processors, smoothed updates, and an SPSC coefficient queue.
- CMake vendoring and relocatable `find_package()` integration, examples,
  benchmarks, English/Japanese documentation, and regression tests.
- Hosted Windows MSVC, Linux GCC/Clang, macOS AppleClang, and Linux ASan/UBSan
  checks pass before the release is published.

The API is pre-1.0. Coefficient design belongs on a worker thread; the fit-error
estimate is sampled, fractional slopes are finite-band approximations, and
analog phase is not reproduced. See the README, validation notes, and threading
contracts for supported parameters and practical limits.

Assets include a source ZIP, its SHA-256 checksum, and a per-file SHA-256
manifest. This release contains the library and its documentation/tests;
the Valence plug-in and external toolchains are separate projects.
